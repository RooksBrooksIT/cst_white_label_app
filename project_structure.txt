2. ROLE-BASED MODULE SUMMARY
================================================================================

┌───────────────────────┬──────────────────────────────────────────────────────┐
│ Role Module           │ Core Responsibilities & Capabilities                 │
├───────────────────────┼──────────────────────────────────────────────────────┤
│ 1. Organization Admin │ • Managed under `lib/screens/organization/`          │
│                       │ • Company registration & workspace setup             │
│                       │ • Subscription plan management (Silver/Gold/Platinum)│
│                       │ • PayU payment gateway checkout & billing audit       │
│                       │ • Organization-wide financial & site oversight       │
│                       │                                                      │
│ 2. Project Manager    │ • Managed under `lib/screens/manager/`               │
│                       │ • Creation and configuration of projects & sites     │
│                       │ • Approval of material requests & site expenses      │
│                       │ • Inventory management (Materials, Vehicles, Tools)  │
│                       │ • Assignment of supervisors, contractors, & workers  │
│                       │                                                      │
│ 3. Site Supervisor    │ • Managed under `lib/screens/supervisor/`            │
│                       │ • Daily site entry and work schedule execution       │
│                       │ • Recording worker daily attendance & shift logs     │
│                       │ • Material arrival logging & indent requests         │
│                       │ • Equipment/tool movements between sites             │
│                       │                                                      │
│ 4. Customer / Client  │ • Managed under `lib/screens/customer/`              │
│                       │ • Read-only client view of project progress & sites  │
│                       │ • Financial progress & payment milestone reports     │
│                       │ • Deployed manpower and site activity summaries      │
│                       │                                                      │
│ 5. Reports & Audits   │ • Managed under `lib/screens/reports/`               │
│                       │ • Comprehensive PDF generation (Daily logs, PDF export)│
│                       │ • Financial, material, worker, and vehicle audits    │
│                       │ • Interactive KPI & analytics dashboards             │
│                       │                                                      │
│ 6. Branding Engine    │ • Managed under `lib/screens/branding/`              │
│                       │ • White-label customization (App Name, Primary Color)│
│                       │ • Dynamic theme persistence across all screens       │
└───────────────────────┴──────────────────────────────────────────────────────┘
